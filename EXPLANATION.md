# Needs your call

By Hamzat Adebayo (Team Cybertron).

## The problem

Agents now take fixes from proposal to live on their own. A person is only needed when something falls out of that path. Today those items are mixed in with everything else, as long text you have to read one by one. With 200 of them, nobody can keep up.

## The idea

One list in the Inbox: **only the items that need a person**, and you can clear it in minutes.

- **One line per item.** No paragraphs.
- **A tag says why it's here**, and each tag has one action:

| Tag | Action |
| --- | --- |
| Big change | Approve |
| Agents split | Ship it / Hold |
| No test proof | Send back |
| Rolled back | Approve the project note |

- **Dots show where it stopped:** Proposal, Working, Ready, Staging, Live.
- **Faces show what the agents think:** ✓ or ✗ each. Hover a face for its reason.
- **Open a row for context:** screenshots, the agent who disagreed, the proposed note.

## Built for volume

- Grouped by tag, with a bulk action per group ("Approve all 50").
- Select several, then act on them from one bar.
- Keyboard: J and K to move, A to act, X to select.
- Every action can be undone for a few seconds.
- The mock-up has 200 items, so you can test it at full size.

## Try it

Open **Product → Inbox → Needs your call**.
